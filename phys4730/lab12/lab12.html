Exercise 1.

Today's lab is a simple plotting exercise, designed to reinforce the idea of Fisher Information. You will calculate and plot the Fisher information for two normal PDFs


We will take the widths of these distributions — σ1 and σ2 — to be known, and compute Fisher information for the parameters θ1 and θ2.

Consider cases in which f1 and f2 have the different means and the same width, e.g.

    θ1, σ1 = 1.0, 0.3
    θ2, σ2 = 2.0, 0.3

and also the case where f1 and f2 have the same means and different widths, e.g.

    θ1, σ1 = 2.0, 0.3
    θ2, σ2 = 2.0, 0.6

Create a Python script (or Jupyter Notebook) to perform the following:

  1. Generate an appropriately-sized (i.e. readable) 5-panel plot. The horizontal axis should span -10.0 < x < 10.0, in small steps.

  2. The five panels should be:

    • Overlay of the two PDFs
    • Overlay of ln(PDF)
    • Overlay of ln(PDF)' (derivative w.r.t. θ)
    • Overlay of (ln(PDF)')2
    • Overlay of the integrand needed to calculate I(θ)

  3. Your code should do a numerical integration of the integrands in panel 5, and output Fisher information for the two PDFs.

  4. Can you relate the Fisher information to the values of the parameters (θi, σi)? Does the behavior of the Fisher Information with changes in θi and σi agree with your intuitive understanding of information?

  5. Finally, your code should produce an output figure fisher.png.
