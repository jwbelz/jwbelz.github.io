Exercise 2.

Prepare a standalone Python script findquadratic.py to perform the following:

  • Read data from quaddata.dat , assumed to be in the current working directory.

  • Suppose a model predicts this data should be described by a quadratic polynomial, i.e.

    y(x) = a0 + a1x + a2x2

    Set up the appropriate Vandermonde matrix, invert it using numpy.linalg.pinv, and find the solution vector a = (a0,a1,a2).

  • For output, print the values of the solution vector a to standard output. Also, produce a plot of the data with superimposed quadratic fit. Save this plot in the file findquadratic.png.
Your code should run on the Physics Department Linux Cluster, with the command python3 findquadratic.py.
