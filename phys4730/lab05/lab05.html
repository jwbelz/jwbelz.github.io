Exercise 1.

Start by using a random number generator to simulate the flip of an unbiased coin. Try to find the probability of getting exactly the same number of heads and tails in a sequence of 10 coin flips. This code snippet might be useful: 

import random

def headsortails():
    return random.choice(['H','T'])

nflips = 10       # number of coin flips to simulate
ntries = 1000000  # number of times to simulate the flipping of nflips coins

nheadstails = 0   # a counter, number of times nheads = ntails

for i in range(0,ntries):

    nheads = 0
    ntails = 0

    for j in range(0,nflips):

        result = headsortails()
        if(result == 'H'):
            nheads += 1
        else:
            ntails += 1

    if(nheads == ntails): nheadstails += 1

prob = float(nheadstails)/float(ntries)

Print the results of this calculation to standard output (i.e. the terminal). Can you also calculate and print out the expected error of this result, based on the in-class discussion?

Exercise 2.

Now, let's compare the result of Exercise 1 with the theoretical prediction based on the binomial distribution. This function definition should do the trick: 

 
def binomial_pdf(p,n,k):

#   calculates the binomial probability of obtaining exactly k occurrences
#   of some event (whose likelihood is p) in n independent trials. 
    
    return factorial(n)/(factorial(k)*factorial(n-k))*pow(p,k)*pow(1.0-p,n-k)

(Note that this function in turn calls a function named factorial. Perhaps you already wrote this function when you were learning Python. Or you could just use the factorial function from the Python math library.)

Here, n is the number of coin flips, p is the likelihood of a certain outcome — say the coin landing on heads, so p=0.5 — and k is a certain number of occurrences of that outcome. The function returns the probability of getting exactly k occurrences of some event (like coin landing on heads) in n trials (coin flips), given that in each trial the likelihood of getting that event is p (for a fair coin, p=0.5). So, to find the chance of getting exactly 4 heads in 12 coin flips, use 

     
p = 0.5
n = 12
k = 4
binomialProbability = binomial_pdf(p,n,k)
If you've done things correctly, the binomial probability should agree with the random coin flip experiment of Exercise 1, within statistical uncertainty.

If the number of trials n becomes large, the standard form for the binomial distribution can become problematic due to machine limitations on computing factorials for very large numbers. Instead, one can use a Gaussian approximation to get an estimate: 

 
def binomial_pdf_approx(p,n,k):

#   calculates the gaussian approximation to a binomial
#   probability of getting exactly k occurrences of some
#   event (whose likelihood is p) in n independent trials.

    x = k-n*p 
    var = n*p*(1-p)
