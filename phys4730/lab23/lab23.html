Exercise 1.

Create a Python script or Jupyter Notebook to read and apply the kNN classification algorithm to the full Habitable Worlds Catalog data set. For starters, just use two features (e.g. stellar mass and orbital period) for the classification. Be sure that the training data is appropriately scaled for use with kNN.

If you are able to get that working, here are some variants to try:

  • Try adding additional features to the classifier. Are there any that we have not tried in lab or lecture that you think may be relevant?

  • Try varying k. Does it make any difference in the performance?

  • Instead of weighing each of the k nearest neighbors uniformly, it is possible to weigh them according to distance or a user-defined function. Can you get this functionality to work?

  • To think about: How are kNN and DT similar and different in performance? Are there cases where one or the other would be clearly preferable? Next week we will begin looking at tools to provide quantitative answers to these questions.
