Exercise 2.

Prepare a standalone Python script (not a notebook!) gaussplot.py that

  • Generates 10,000 random numbers in a Gaussian (normal) distribution with a mean <x> = 10.0 and a width σx = 3.0.

  • Sorts these numbers into bins of width Δx = 0.2. Convenient ways of doing this include the matplotlib.pyplot.hist or numpy.histogram functions.

  • Plots the contents of each bin, with √N errorbars, versus the center of the bin. As with any plot you produce in this course, the axes should be carefully labeled. Output this plot to the file gaussplot.png.
Your code should run on the Physics Department Linux Cluster, with the command

python3 gaussplot.py
