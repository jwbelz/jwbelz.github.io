Mandatory Assignment, due 25 August 2026 in class

Problem 1

The assignments, exams, and projects for this course will be submitted electronically using the submit utility. The purpose of this exercise is to practice using this utility.

Some general instructions for the submit system are:

  • The general form of a command is submit p4730 [assignment] [file1] [file2] [file3]...

  • If you type only submit p4730 you will get a list of pending assignments. Try it!

  • If you type submit p4730 [assignment] you will get a listing of files you have submitted for this assignment. Of course, if you haven't yet submitted anything the list will be empty.

  • You may submit several files at once, or one at a time. You can resubmit files up until the due date. Note that if you resubmit a file, the original submitted version of that file will be lost.

  • A common pitfall of this system is submitting files with names that do not exactly match what the assignment requires. In Linux, remember that file names are case-sensitive.

Now, please perform the following:

  1. Create a file called exactly 
    Lab01_Problem01.txt
  2. In this file, provide brief responses to the following:

    (a) What was the highlight of your summer break?

    (b) Please describe your previous computing experience. List any prior programming courses that you have taken. List any programming languages and operating systems with which you are familiar.

  3. Submit your file for grading with the command: 
     submit p4730 lab01 Lab01_Problem01.txt
  4. Check your submission with the command: 
     submit p4730 lab01
    You should get a notice that your file has been received.

  5. Await your grade report via email (may take a few days...)
