Exercise 1.

This lab was originally created by Prof. Michael Vershinin.

The Kolmogorov-Smirnov (KS) test is designed to test data against a known distribution or two independent data sets against each other, as we saw in Lab 16. But it is not valid to estimate parameters for the distribution of interest from data and then apply the KS test against the distribution with estimated parameters. For example, you should not take data that looks like it comes from a Gaussian distribution, estimate location and width, and then perform a KS test between the data and the Gaussian distribution with the estimated parameters.

But, if we are clever we can create our own KS-like statistic for such a scenario and evaluate the significances using a Monte Carlo technique. Following Lilliefors, let’s carry out this procedure for a normal distribution with estimated parameters.

  1. Write a function to compute Lilliefors' statistic for normal distribution. The function should take one input: the number of data points Npts in the dataset, and output a single number:

    1. Generate an independent normal data set of size = Npts. You can use any mean and width you want.

    2. Estimate the mean and standard deviation from the data set. Be careful to use the Bessel correction for standard deviation (you can use numpy.std but with ddof=1).

    3. Form a normalized data set by subtracting mean and dividing by standard deviation.

    4. Compute ECDF and theoretical CDF. Make sure ECDF starts at zero and ends in 1. I suggest sorting the data into 1,000 or so small bins between -10 σ and +10 σ.

    5. Compute the absolute value of the maximum vertical deviation or supremum between ECDF and CDF.

    6. Return the supremum as our test statistic.

  2. Now, in your main script call this function to compute the Lilliefors statistic for many (10,000 or more) data sets of sample size Npts. Apply np.quantile to the resultant distribution to find critical values of the test statistic, corresponding to significances and null-hypothesis confidence intervals.

    For Npts = 12, output a set of numbers that can be compared against the corresponding row in Table 1 of Lilliefors.
